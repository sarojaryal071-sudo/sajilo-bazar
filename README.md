# Sajilo Bazar

Local services marketplace connecting skilled youth to households in Nepal.

**If you are the implementation session picking this up: start with `docs/PROJECT_BRIEF.md`,
then `docs/DATA_MODEL.md`, `docs/SCREENS.md`, and `docs/DESIGN_SYSTEM.md`, in that order,
before writing any code.** These four documents are the spec. The old `sajilo-app` /
`sajilo-backend` repos (referenced within these docs) are for feature-parity reference
only — do not copy their code or structure directly; they're the thing being rebuilt away
from.

Report progress and any judgment calls back to the planning session rather than deciding
product questions unilaterally.
